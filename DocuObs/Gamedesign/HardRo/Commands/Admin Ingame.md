# 📋 GM Команды для управления игроками

## 📊 Информационные команды

|Команда|Синтаксис|Описание|
|---|---|---|
|**#statsall**|`#statsall <имя_игрока>`|Устанавливает все характеристики игрока на максимум|
|**#itemlist**|`#itemlist <имя_игрока>`|Показывает все предметы в инвентаре игрока|
|**#storagelist**|`#storagelist <имя_игрока>`|Показывает все предметы на складе игрока|
|**#stats**|`#stats <имя_игрока>`|Показывает характеристики персонажа|

Для заточки оружия (и брони) в rAthena используются две основные GM-команды, в зависимости от того, хотите ли вы улучшить уже надетое оружие или создать новое сразу с заточкой.

1. Заточка уже надетого оружия

Команда изменяет уровень улучшения для предметов, которые в данный момент экипированы на персонаже.

- `@refine <позиция> <уровень заточки>`
    - **Пример:** `@refine 2 10` — точит оружие в правой руке до +10.

**Основные ID позиций экипировки:**

- `2` — Правая рука (Оружие / Weapon)
- `3` — Левая рука (Щит / Второе оружие у Ассасинов)
- `1` — Нижняя часть головы (Lower Headgear)
- `4` — Накидка 
- `16` — Тело 
- `32` — Щит
- `64` — Аксессуар 1 (левый)
- `128` — Аксессуар 2 (правый)
- `256` — Верхняя часть головы (Top Headgear)
- `512` — Средняя часть головы (Mid Headgear)

2. Создание нового оружия с заточкой

Если вам нужно сразу выдать готовое заточенное оружие, используйте команду генерации предмета по ID или названию. [[1](https://github.com/rathena/rathena/blob/master/conf/msg_conf/map_msg_rus.conf)]

- `@item2 <ID или Имя> <количество> <идентификация> <заточка> <элемент> <карта1> <карта2> <карта3> <карта4>`
    - **Пример:** `@item2 1101 1 1 10 0 0 0 0 0` — создает один Меч (Sword, ID 1101), идентифицированный (1), с заточкой +10, без элемента и без карт. [[1](https://github.com/rathena/rathena/blob/master/conf/msg_conf/map_msg_rus.conf)]

Если вы хотите узнать больше о скриптовых командах, напишите, требуется ли вам **написать NPC-кузнеца** или **изменить шансы безопасной заточки** в конфигурационных файлах сервера?
